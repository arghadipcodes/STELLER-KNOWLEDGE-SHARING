# 📚 Knowledge Sharing Smart Contract (Soroban - Stellar)

## 📖 Project Description

This project is a decentralized Knowledge Sharing platform built using Soroban smart contracts on the Stellar blockchain. It allows users to create, store, and interact with knowledge posts in a secure and decentralized way.

The goal is to eliminate centralized control and give users ownership of their content.

---

## ⚙️ What it does

* Users can create knowledge posts (articles, notes, ideas)
* Each post is stored on the blockchain
* Other users can like posts
* All data is transparent and tamper-proof

---

## ✨ Features

* 🧠 Decentralized knowledge sharing
* 🔐 Secure and immutable storage
* 👍 Like/upvote system
* 👤 Author tracking
* 📊 Simple post management (create, read, like)
